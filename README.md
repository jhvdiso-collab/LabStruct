# LabStruct — C++17

Версии: [C++](https://github.com/jhvdiso-collab/LabStruct/tree/c%2B%2B-version), [Go](https://github.com/jhvdiso-collab/LabStruct/tree/go-version). В `main` находятся обе реализации и проверки совместимости.

Массив, списки, стек, очередь и АВЛ. Требуются CMake >= 3.20, C++17 и Python 3; Linux/macOS.

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build -j2
ctest --test-dir build --output-on-failure
./dbms --file file.data --query 'MPUSH numbers 10'
```

Полная проверка ветки: `bash scripts/check.sh`. Справочник: [COMMANDS.md](COMMANDS.md).

## Общие правила

- Имена: непустая последовательность `A–Z`, `a–z`, `0–9`, `_`, `-`.
  Одно имя относится ровно к одной структуре, регистр учитывается.
- Команды пишутся заглавными буквами. Числа — десятичные от −2147483648 до
  2147483647, без ведущего `+`. Индексы начинаются с нуля.
- `MCREATE name`, `FCREATE name`, `LCREATE name`, `SCREATE name`, `QCREATE name`,
  `TCREATE name` создают пустую структуру и возвращают `OK`. Повторное создание — ошибка.
- `…PUSH`, `…PUSHFRONT`, `…PUSHBACK` и `TINSERT` создают отсутствующий контейнер
  автоматически. Другие операции требуют существующего контейнера.
- `PRINT name` выводит любую структуру как `[10 20 30]`, пустую — `[]`.
  Стек выводится от вершины, очередь — от головы, дерево — по возрастанию.
- Добавление в линейную структуру и замена возвращают записанное значение;
  удаление по индексу/с конца/начала возвращает удалённое значение.
- Отрицательный/несуществующий индекс, извлечение из пустой структуры, неправильное
  имя, тип, число аргументов или повреждённый файл — ошибка. Ошибочная команда не
  изменяет файл. Значение `-1` допустимо в стеке/очереди и не служит признаком ошибки.

## Массив — M

| Команда | Действие |
|---|---|
| `MPUSH name value` | Добавить в конец |
| `MINSERT name index value` | Вставить по индексу; разрешён индекс, равный длине |
| `MGET name index` | Получить значение |
| `MDEL name index` | Удалить по индексу |
| `MSET name index value` | Заменить значение |
| `MLEN name` | Получить длину |
| `PRINT name` | Прочитать все элементы |

## Списки — F и L

Ниже `X` нужно заменить на `F` (односвязный) или `L` (двусвязный).
Индекс в операциях **BEFORE/AFTER обозначает существующий опорный элемент**.
Например, для `[10 20 30]` команда `FDELAFTER name 0` удаляет `20`.

| Команда | Действие |
|---|---|
| `XPUSH name value`, `XPUSHBACK name value` | Вставка в хвост |
| `XPUSHFRONT name value` | Вставка в голову |
| `XPUSHBEFORE name index value` | Вставка до опорного элемента |
| `XPUSHAFTER name index value` | Вставка после опорного элемента |
| `XDELFRONT name` | Удаление головы |
| `XDELBACK name` | Удаление хвоста |
| `XDELBEFORE name index` | Удаление перед опорным элементом |
| `XDELAFTER name index` | Удаление после опорного элемента |
| `XDEL name index` | Удаление по индексу |
| `XDELVAL name value` | Удалить первое совпадение; вернуть `TRUE`/`FALSE` |
| `XFIND name value` | Индекс первого совпадения; `-1`, если нет |
| `XGET name index` | Чтение по индексу |
| `XLEN name` | Длина |
| `XREVERSE name` | Прочитать в обратном порядке, **не изменяя** список |
| `PRINT name` | Прочитать в прямом порядке |

Для односвязного списка обратное чтение использует временный буфер; для двусвязного
проход выполняется по `prev`. Вставка/удаление до/после за границами — ошибка,
а не неявное добавление или удаление другого элемента.

## Стек — S, очередь — Q

| Команда | Действие |
|---|---|
| `SPUSH name value`, `QPUSH name value` | Добавить значение |
| `SPOP name`, `QPOP name` | Прочитать и удалить по LIFO/FIFO |
| `SGET name`, `QGET name` | Прочитать следующее значение без удаления |
| `PRINT name` | Прочитать всё без удаления |

## АВЛ — T (только C++)

| Команда | Действие |
|---|---|
| `TINSERT name value` | Вставить с балансировкой; `TRUE`, если новый ключ |
| `TGET name value`, `ISMEMBER name value` | Проверить наличие, `TRUE`/`FALSE` |
| `TDEL name value` | Удалить с балансировкой; `TRUE`, если ключ был |
| `PRINT name` | Симметричный обход |
| `TSHOW name` | Схема дерева с высотами и балансом узлов; пустое дерево — `[]` |

В схеме `ROOT` обозначает корень, `L` и `R` — левого и правого потомка,
отступ — глубину. `h` — высота узла, `b` — высота правого поддерева минус
высота левого. Отсутствующие потомки не выводятся. `TSHOW` не изменяет файл
и показывает дерево после загрузки в текущем запуске. Пример схемы и поворота
приведён в разделе АВЛ отчёта.

АВЛ хранит уникальные ключи. Повторная вставка и удаление отсутствующего ключа
возвращают `FALSE` и не перезаписывают файл. Для других структур дубликаты разрешены.
Go не выполняет операции над деревьями; при изменении линейных структур в общем файле
Go сохраняет записи деревьев, созданные C++.

## Формат и сохранность данных

Текстовый UTF-8 файл, заголовок `LABSTRUCT 1`, затем одна строка на контейнер:

```text
LABSTRUCT 1
M numbers 3 10 20 30
S stack 2 200 100
T tree 3 10 20 30
```

Строка: `тип имя количество значения…`. Порядок значений совпадает с `PRINT`;
порядок строк при записи — по имени. Для дерева сохраняются ключи, при загрузке
строится корректное АВЛ; точная форма дерева между запусками не фиксируется.
Отсутствующий файл означает пустую базу, но существующий пустой или повреждённый
файл считается ошибкой, чтобы не затереть данные случайно.

Изменения записываются во временный файл в том же каталоге, затем файл атомарно
переименовывается. Чтение не перезаписывает данные. Нужны права чтения файла и
записи в его каталог. Родительский каталог должен существовать. Формат совместим
между C++ и Go. Одновременные изменения одного файла несколькими процессами
не поддерживаются; гарантия сохранности при отключении питания не заявляется.
